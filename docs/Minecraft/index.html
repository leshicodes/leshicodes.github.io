Nutville Minecraft Server Documentation

Server Information​

  • Server Address: mc.nutville.jjambrose.info
  • Minecraft Version: 1.21.10
  • Access: Allowlist only - message me your Minecraft username on Discord
  • Server Status: status.jjambrose.info

Getting Started​

1. Connect to the Server​

  1. Launch Minecraft 1.21.10
  2. Go to Multiplayer
  3. Add Server
  4. Enter server address: mc.nutville.jjambrose.info
  5. Connect and enjoy!
tip

Check the server status page to see if the server is online before connecting.

Optional: Client-Side Modpack​

The server has an optional client-side modpack that includes:

  • Performance optimizations
  • Shader support
  • Distant Horizons mod

Install CurseForge​

Download and install the standalone version of CurseForge: https://www.curseforge.com/download/app

warning

Important: Download the STANDALONE version, not the Overwolf version.

Install the Modpack​

Method 1: Import from ZIP (Recommended)​

  1. Download the modpack: Nutville Minecraft 1.21.10.zip
  2. Open CurseForge
  3. Navigate to My Modpacks
  4. Click Import
  5. Select Import as .ZIP
  6. Choose the downloaded file

Configure RAM Allocation (Important!)​

important

The modpack requires significant RAM for optimal performance. The default allocation is a bit overkill so you may need to adjust it.

After importing the modpack, you must configure the RAM allocation for optimal performance:

  1. In CurseForge, find the Nutville Minecraft 1.21.10 profile
  2. Click the three dots in the top right corner of the profile
  3. Select Profile Settings
  4. Under Memory Settings, select Custom RAM Allocation
  5. Set the slider to 16GB (16192MB) for best performance
    • If 16GB is too high for your system, Distant Horizons recommends a minimum of 6GB for stable operation

Server Plugins​

The server is running the following plugins:

  • AxGraves - Custom grave system for player deaths

Support​

If you need to be added to the allowlist or have any issues, contact me on Discord.
